# 用例：线索卡槽滚动

- 日期：2026-11-08
- 目标：把"三槽位线索卡滚动"写成可直接开发的剧本样例
- 前置：依赖 `doc/分析-线索卡滚动与立绘数量上限.md` 第七节的改动（常驻立绘扩成多个槽位）
- 本文档里的 **`<animation:N>`（N = 槽位号）是待实现的新语法**；其余（`<move:>`、`pass_in_*`、`black_*`、对话行）都是**现有能力**

---

## 0. 这个用例依赖的最小改动

| 现状 | 本用例要求 |
|---|---|
| `<animation>:对象` 只能设置唯一的常驻立绘 `AmS` | `<animation:N>:对象` 可设置 `AmS1`–`AmS4`（N 省略时等价于 1，旧剧本不变） |
| 时间轴只有 `AmS` 一组列 | 有 `AmS1`–`AmS4` 各 6 列 |
| `zorder` 里只有 `AmS` | 里 `AmS1`–`AmS4` 依次插在 `Bb` 之前 |

除此之外**不需要任何新语法**——滚动效果完全靠"改基准位置 + 一节内的滑入"组合出来。

---

## 1. 舞台几何

一张卡宽 400px（高任意），横向中心对齐：

| 槽位 | 中心 x | y | 说明 |
|---|---|---|---|
| 槽 0 | **-240** | 540 | 屏外左侧（新卡的起点） |
| 槽 1 | **360** | 540 | 可见，最左 |
| 槽 2 | **960** | 540 | 可见，中间 |
| 槽 3 | **1560** | 540 | 可见，最右 |
| 槽 4 | **2160** | 540 | 屏外右侧（旧卡的终点） |

**槽距 `W = 600`**。选择依据：要保证"槽 4 完全出画"，必须满足 `槽3_x + W - 半宽 > 1920`，
即 `2W > 960 + 半宽`；卡宽 400（半宽 200）时 `W > 580`。取 600 留出余量。

> 这个几何是整个效果的支点：**第 4 个槽天然在屏幕外**，所以"最旧的卡滑出去"和"其他卡滑一格"
> 可以用**完全相同**的位移量和时长，不需要给离场卡特殊处理。

---

## 2. 核心不变式

滚动一次之后的槽位内容：

```
AmS4 ← 原来在槽 3 的卡       （滑到屏外）
AmS3 ← 原来在槽 2 的卡
AmS2 ← 原来在槽 1 的卡
AmS1 ← 新插入的卡
```

并且**每张卡的基准位置 = 它的新槽位**，然后四张卡统一用同一个方法串滑入：

```rgl
<animation:1><black_pass_in_right_600=15>:新卡      # 新卡：淡入 + 滑入
<animation:2><pass_in_right_600=15>:原1号卡         # 已有卡：纯滑入
<animation:3><pass_in_right_600=15>:原2号卡
<animation:4><pass_in_right_600=15>:原3号卡         # 滑到屏外
```

四行是"同时播放"的关键：它们**连续写在同一个小节之前**，所以都在同一帧开始生效。

`pass_in_right_600=15` 的含义（`MotionMethod` 解析，已实测）：

| 片段 | 效果 |
|---|---|
| `pass` | 运动模式 = 平移进出 |
| `in` | 只做**切入**：偏移从 -600 在 15 帧内线性回到 0，之后一直保持 0 |
| `right` | 向右移动（等价于从左侧滑入） |
| `600` | 位移量 = 600 像素（正数即像素，不用 `major` 之类的预设） |
| `=15` | 时长 15 帧（0.5 s @30fps） |

`black_` 前缀额外让新卡从透明淡入（`black` = 淡入淡出模式，`in` 让它在结尾不淡出）。

## 3. 完整剧本示例

假设四张卡图 `线索_抓痕`、`线索_湿脚印`、`线索_钥匙`、`线索_血字` 都已在媒体定义里
声明为 `Animation`（单帧 PNG 即可）。

```rgl
# ============================================================
# 初始化：四个槽位清空，保证第一个镜头是空舞台
# ============================================================
<animation:1>:NA
<animation:2>:NA
<animation:3>:NA
<animation:4>:NA

<background>:旅馆走廊
[旁白]:走廊尽头的门虚掩着。

# ============================================================
# 第 1 次插入：线索「抓痕」进入槽 1
#   旧卡：无（三个槽都是 NA）
# ============================================================
<move:线索_抓痕>:(360,540)
<animation:1><black_pass_in_right_600=15>:线索_抓痕
<animation:2>:NA
<animation:3>:NA
<animation:4>:NA
[旁白]:墙上有三道新鲜的抓痕。

# ============================================================
# 第 2 次插入：线索「湿脚印」进入槽 1，抓痕 1→2
# ============================================================
<move:线索_抓痕>:(960,540)
<move:线索_湿脚印>:(360,540)
<animation:1><black_pass_in_right_600=15>:线索_湿脚印
<animation:2><pass_in_right_600=15>:线索_抓痕
<animation:3>:NA
<animation:4>:NA
[旁白]:地上有一串湿脚印，从门口一直延伸过来。

# ============================================================
# 第 3 次插入：钥匙进 1，湿脚印 1→2，抓痕 2→3
# ============================================================
<move:线索_抓痕>:(1560,540)
<move:线索_湿脚印>:(960,540)
<move:线索_钥匙>:(360,540)
<animation:1><black_pass_in_right_600=15>:线索_钥匙
<animation:2><pass_in_right_600=15>:线索_湿脚印
<animation:3><pass_in_right_600=15>:线索_抓痕
<animation:4>:NA
[旁白]:门缝里卡着一把黄铜钥匙。

# ============================================================
# 第 4 次插入：血字进 1，钥匙→2，湿脚印→3，抓痕 3→4（滑出屏幕）
# ============================================================
<move:线索_抓痕>:(2160,540)
<move:线索_湿脚印>:(1560,540)
<move:线索_钥匙>:(960,540)
<move:线索_血字>:(360,540)
<animation:1><black_pass_in_right_600=15>:线索_血字
<animation:2><pass_in_right_600=15>:线索_钥匙
<animation:3><pass_in_right_600=15>:线索_湿脚印
<animation:4><pass_in_right_600=15>:线索_抓痕
[旁白]:门板上用血写着三个字：不要开。

# ============================================================
# 第 5 次插入：抓痕已经出画，直接不再出现
# ============================================================
<move:线索_湿脚印>:(2160,540)
<move:线索_钥匙>:(1560,540)
<move:线索_血字>:(960,540)
<move:线索_日记页>:(360,540)
<animation:1><black_pass_in_right_600=15>:线索_日记页
<animation:2><pass_in_right_600=15>:线索_血字
<animation:3><pass_in_right_600=15>:线索_钥匙
<animation:4><pass_in_right_600=15>:线索_湿脚印
[旁白]:地上的湿脚印旁边，多了一页被撕下来的日记。
```

### 插入模板（每次插入只需替换占位符）

```rgl
<move:{原3号卡}>:(2160,540)
<move:{原2号卡}>:(1560,540)
<move:{原1号卡}>:(960,540)
<move:{新卡}>:(360,540)
<animation:1><black_pass_in_right_600=15>:{新卡}
<animation:2><pass_in_right_600=15>:{原1号卡}
<animation:3><pass_in_right_600=15>:{原2号卡}
<animation:4><pass_in_right_600=15>:{原3号卡}
```

第一次插入时，三个"原 N 号卡"写成 `NA` 即可。
**注意 `<move:>` 必须写在 `<animation:N>` 之前**——放置行会读取媒体当前的 `pos` 作为中心。

## 4. 逐帧验收标准

以第 2 次插入为例，假设它落在第 12 个小节、该小节第 0 帧的绝对帧号是 `F`：

| 绝对帧 | `AmS1` | `AmS1_c` | `AmS1_p` | `AmS2_c` | `AmS2_p` |
|---|---|---|---|---|---|
| F+0 | 线索_湿脚印 | (360,540) | **(-600,0)** | (960,540) | **(-600,0)** |
| F+7 | 同上 | (360,540) | (-300,0) | (960,540) | (-300,0) |
| F+14 | 同上 | (360,540) | **(0,0)** | (960,540) | **(0,0)** |
| F+30 | 同上 | (360,540) | (0,0) | (960,540) | (0,0) |

（线性插值，步长 600/14 ≈ 42.86px/帧；表中数值取自 `MotionMethod('pass_in_right_600', 15, linear).motion(40)` 的实测输出。）

即：**中心列固定为新槽位，位移列从 -600 线性回到 0，15 帧后归零并保持**。
带 `black_` 前缀时 `_a` 同步从 0 爬到 100（同样 15 帧），不带则恒为 100。

可以直接用解析器验（脱离 GUI）：

```python
log = RplGenLog(file_input='剧本.rgl')
tl = log.execute(media_define=md, char_table=ct, config=config)
# 以第 2 次插入实际落在的小节号为准（这里假设是 12）
sub = tl[tl['section'].astype(str) == '12']
print(sub['AmS1_c'].tolist()[:3])     # ['(360,540)', '(360,540)', …]
print(sub['AmS1_p'].tolist()[:16])    # ['(-600,0)', …（线性插值）… '(0,0)', '(0,0)']
print(sub['AmS4_p'].tolist()[:16])    # 同样是 (-600,0) → (0,0)
```

判据：同一小节内，`AmS1..AmS4` 的 `_c` 恒为新槽位、`_p` 在第 0 帧等于 `(-600,0)`、第 15 帧起恒为 `(0,0)`。

## 5. 变体

### 5.1 新卡不要淡入，只要位移

去掉 `black_` 前缀：

```rgl
<animation:1><pass_in_right_600=15>:线索_湿脚印
```

### 5.2 反向滚动（新卡从右边进，旧卡从左边出）

槽位镜像：`槽1=1560, 槽2=960, 槽3=360, 槽0=2160, 槽4=-240`，方法改成 `pass_in_left_600`。

```rgl
<move:{新卡}>:(1560,540)
<animation:1><pass_in_left_600=15>:{新卡}
```

### 5.3 想同时显示 4 张可见卡

`W` 和半宽的关系要重算：4 张可见 + 1 张屏外，就需要 `槽4_x - W*…`，最省事的做法是
把卡宽缩到 300（半宽 150）并取 `W = 420`，槽位 `330 / 750 / 1170 / 1590`，槽 5 在 2010（屏外）。

### 5.4 只换内容、不滚动（同一槽位换图）

```rgl
<move:线索_新>:(960,540)
<animation:2><black_in=10>:线索_新      # 原地淡入替换
```

### 5.5 清空全部

```rgl
<animation:1>:NA
<animation:2>:NA
<animation:3>:NA
<animation:4>:NA
```

## 6. 编写规则与已知的坑

| # | 规则 | 原因 |
|---|---|---|
| 1 | `<move:>` 必须写在对应的 `<animation:N>` **之前** | 放置行读取的是媒体**当前**的 `pos` |
| 2 | `<move:>` 的目标必须是**动画媒体名**（如 `线索_抓痕`），不要对共享的 `FreePos` 对象用 | 移动 `FreePos` 会**原地改写**对象，导致上一段的中心被追溯修改；移动动画媒体是**重新绑定**，历史安全 |
| 3 | 一次滚动的四条 `<animation:N>` 必须**连续写、中间不插对话行** | 它们要在同一帧开始生效 |
| 4 | 任何两次滚动的间隔要 **≥ 2×时长+1 帧**（这里 ≥31 帧） | `place_anime_execute` 在跨度不足时会**丢弃**动画并打印 `PAmMetDrop` 警告 |
| 5 | 离场的卡不需要特殊处理，它会自己滑到屏外；下一次不再写它就等于删除 | 第 4 槽在屏外 |
| 6 | `zorder` 里 `AmS1`–`AmS4` 要排在 `Bb` **之前** | 否则卡片会盖住对话气泡 |
| 7 | 卡图必须是**单帧** `Animation`（PNG）；多帧动画可以用，但组合立绘（`GroupedAnimation`）不支持 | 见分析报告 1.4 / 7.2 |
| 8 | 卡片之间的遮挡顺序无所谓 | 它们始终相隔一个槽距，不会重叠 |

### 6.1 关于"同时播放"的语义

四条 `<animation:N>` 是**四条独立的放置指令**，各自带自己的方法串和时长。它们之所以"同时"，
是因为都写在同一个小节之前，于是都在**同一个小节的第一帧**生效。理论上你可以让每张卡
用不同的方向/时长/缓动——这正是扩 `AmS` 相对扩 `Am` 的优势（`Am` 的位移是整节共享的）。

## 附：为什么不用扩 `Am` 的方式做同样的事

`Am1`–`Am3` 的位移 `_p` 是**整节共享**的（一节只算一个 `MotionMethod`），所以：
- 四张卡无法用不同方向/时长；
- 卡片还必须是角色表里的角色，非首要默认 60% 透明；
- 想在第 4 张卡上做"滑出 + 淡出"就得动交叉溶解那套记账。

用 `AmS1..AmS4` 之后，每个槽位有**自己的**方法和中心，上面三条限制全部消失。
